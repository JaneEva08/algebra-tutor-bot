# Algebra Tutor Bot

Telegram-преподаватель алгебры для 7 класса с переключаемой памятью.
Объясняет тему небольшими шагами и задаёт вопросы на понимание.
В этом учебном этапе реализованы история диалога, её сохранение после
перезапуска и очистка. Полная программа и оценка освоения ещё не реализованы.

## Запуск

Нужен Python 3.11+. Сторонних зависимостей нет.

1. Создать бота через BotFather и получить токен.
2. Скопировать `.env.example` в `.env`, заполнить токен и настройки
   OpenAI-совместимого API. Настроить `ALLOWED_USER_IDS` для ограничения доступа.
3. Выполнить:

```bash
python bot.py
```

Процесс должен оставаться запущенным и иметь доступ к интернету.
Постоянный хостинг и автозапуск не входят в этот этап.
Нельзя запускать несколько polling-процессов с одним токеном.
Если уже настроен webhook, бот остановится, не удаляя его автоматически.

## Команды

| Команда | Назначение |
|---|---|
| `/start`, `/help` | Справка и кнопки |
| `/lesson` | Очистить текущую историю и начать занятие |
| `/memory_on` | Использовать и сохранять историю |
| `/memory_off` | Не использовать и не пополнять историю |
| `/status` | Режим и количество сохранённых сообщений |
| `/reset` | Удалить историю пользователя из SQLite |

Выключение памяти не удаляет историю: при включении она возвращается.
Очистка базы не удаляет сообщения из самого Telegram.
История раздельная для каждого Telegram ID; в одном аккаунте профили
разных учеников не переключаются.

## Как устроено

- `core.py` — SQLite и подготовка контекста, независимо от Telegram.
- `bot.py` — команды и long polling Telegram.
- `transport.py` — HTTP-запросы к Telegram и совместимому API модели.
- `lesson.md` — авторский материал по линейным уравнениям.
- `data/tutor.sqlite3` — локальная база, не публикуется.

SQLite хранит 20 последних полных пар вопрос–ответ на пользователя.
На каждом запросе история читается с диска и добавляется в системный
промпт как цитируемые JSON-данные. Контекст ограничен 16000 символами
с удалением старейших целых пар. Это ограниченная история, не вечная память.

## Проверки

```bash
python -m unittest -v
python probe.py
```

Первый запуск: 8 тестов, SQLite реальная, внешние сервисы подменены.
`probe.py` выполняет реальные платные запросы к настроенной модели,
Telegram getMe и проверку восстановления в новом процессе Python.
Сообщения пользователям Telegram при этом не отправляет.
Результаты прогона 03.11.2026 сохранены в `docs/api-checks.json`.
Ручное сравнение режимов и очистка подтверждены 10 скриншотами.

## Ограничения

Бот работает только с текстом в личных чатах. Нет обработки учебников,
векторной БД, автоматической аттестации и родительского кабинета.
Учебный материал авторский, без привязки к номерам реального учебника.
Ответы модели требуют проверки. Запросы обрабатываются последовательно;
при аварии между сохранением ответа и подтверждением обновления Telegram
возможна повторная обработка. Данные учеников, токены и ключи в репозиторий
не включены. Реальный бот для демонстрации ограничен разрешёнными ID.
